The challenge

Today, the riskiest work is done by hand.

Amicorp is a regulated fiduciary. Two compliance journeys carry most of the manual effort and most of the risk, and underneath both sits a data problem.

Payments checked by hand

Before a payment is cleared, a specialist checks country risk, runs World-Check screening and cross-checks client data between 5 Series and CARE.

Statements reconciled a month late

Bank statements arrive about 30 days after execution, as digital and scanned PDFs in many formats. They are reconciled by hand, and exceptions surface late.

Nine systems, no single view

The facts about a client, an entity or a transaction are spread over nine applications, so every team repeats the reconciliation, and AI cannot be applied safely.

The platform

Two capabilities. One platform.

UDAP brings intelligent process automation and a unified data platform together, so the work and the data it depends on are governed in one place.

Intelligent Process Automation

The principle

Rules decide. AI interprets. Humans approve.

Every gate is a versioned rule, every summary is explained, and every final decision has a name next to it.

01

Rules decide

Versioned rulesets evaluate every gate on live data. A change needs a second person to approve it, and its regression cases must pass first.

02

AI interprets

The language model reads, summarises and recommends, citing the evidence it used. It never decides, and an error or a doubt fails closed.

03

Humans approve

A named expert makes every final decision, with the evidence and the AI summary in front of them. The person who prepared a card can never approve it.

Every step is audited. The ruleset version, the values read, the model and prompt version, the decision, who made it and why, all kept so any decision can be replayed years later.

How it works

From exception to decision, on one card.

n8n orchestrates each journey; the platform holds the rules, the card and the audit trail, so every part can be replaced without losing a decision.

  1. Detect

    A scan, an arriving document or a payment request raises the work.

  2. CheckRules

    Versioned rules evaluate each gate on live data from the systems of record.

  3. Assemble

    The platform gathers the evidence and opens one Work Card, never two.

  4. ExplainAI

    AI summarises the evidence and proposes an action, citing its sources.

  5. DecidePeople

    A named expert approves, rejects, returns it to the AI with a note, or delegates it, within a service level.

  6. Write back

    Approved changes return to the core systems through one governed, audited path.

Security and trust

Built for a regulated fiduciary.

Controls are designed in from the first card, not added at the end, and the API enforces every rule again whatever the screen shows.

Hong Kong residency

Every component runs in Amicorp's Huawei Cloud tenant in Hong Kong, across availability zones.

One identity

Microsoft Entra ID signs everyone in, with Amicorp's MFA and conditional access unchanged.

Four eyes

The person who prepares a card never approves it, and every rule change needs a second approver.

Encrypted throughout

TLS in transit, encryption at rest with keys in Huawei DEW, and secrets only in key management.

Tamper-evident audit

An append-only trail where each record carries a hash of the one before, exported daily to locked storage.

Fail closed

A gate or a model that cannot decide holds the work for a person. Nothing passes by default.

Deny by default

Every API route declares exactly one permission, and the API checks every rule on every call.

Private by default

One way in through the web application firewall; everything else on private networks.
